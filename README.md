# 🚀 Developer Portfolio

A modern, responsive portfolio website showcasing my professional experience, projects, technical skills, and achievements.

The portfolio is built with a data-driven approach, where all content—including personal information, experience, projects, skills, education, and certifications—is managed through a single `portfolio-data.json` file, making it easy to maintain and update without modifying the application code.

## ✨ Highlights

- Clean and responsive design
- Dynamic content powered by a centralized JSON file
- Showcases experience, projects, skills, and education
- Easy to customize and extend
- Automatic deployment through GitHub and Vercel
